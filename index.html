Evidence, Not Portfolio Copy

LLM-Powered PDF Question-Answering System (RAG)
Confirmed
Hypothesis
Grounding an LLM's answers in retrieved passages from a source PDF produces more accurate, less hallucinated answers than querying the LLM's parametric knowledge alone.
Method
Chunked and embedded PDF text into a vector store, retrieved the top-k relevant passages per query, and fed them to the LLM under a constrained prompt, compared against a no-retrieval baseline answering from the same questions directly.
Finding
Confirmed — retrieval-grounded answers stayed traceable to source text and cut down the unsupported claims that showed up often in the no-retrieval baseline.
Python · LangChain · Vector Embeddings · LLM API GitHub
Systematic Benchmarking Framework for LLM Prompting Strategies
Nuanced
Hypothesis
More elaborate prompting strategies (chain-of-thought, few-shot, self-consistency) reliably outperform plain zero-shot prompting across task types.
Method
Built a harness that runs an identical task set across multiple prompting strategies and models under matched conditions, scoring each against a shared metric and a zero-shot baseline.
Finding
Nuanced — elaborate strategies helped on reasoning-heavy tasks but showed little to no gain, and occasionally a regression, on simple extraction tasks, so the "always add chain-of-thought" assumption didn't hold uniformly.
Python · LLM APIs · Pandas · Evaluation Harness GitHub

Ongoing — International Research Internship

Satellite-Informed Solar Irradiance Forecasting for Oman

Prof. Ali Al Humairi — Professor of Computer Science, German University of Technology in Oman (GUtech)

Investigating whether satellite-derived cloud and irradiance data can improve next-day solar forecasting accuracy for Muscat, Oman, beyond a naive persistence baseline. Uses real NASA POWER satellite data, time-series cross-validation, and statistical significance testing. Initial results found no significant improvement over persistence overall, with the effect concentrated on clear-sky days — motivating current work validating against real ground-sensor data from GUtech's Shams Solar Facility and testing genuine forecast-based inputs to close the gap on cloudy-day accuracy specifically.
